# The Bandit — shared character-sheet license

These are original character assets generated by **Cinder & Crown** with **Higgsfield** for *The Neon City Bandit* and *Trash Stack*, which share one mascot and cross-promote each other.

- **Created:** 20 November 2026 (America/Chicago)
- **Studio:** Cinder & Crown (Cinder and Crown LLC)
- **Generator:** Higgsfield (Nicholas Will's connected Higgsfield workspace, Ultra plan)
- **Tooling:** Higgsfield MCP `generate_image` and `generate_image_batch` (model `gpt_image_2_6`, shown in the catalog as GPT Image 2.6 Sunburst; job metadata also listed the internal model name `aurora-img-alpha`). Quality: high. Resolution: 1K. Output: transparent PNG. A local alpha cleanup removed leftover haze on some frames (especially the side view); fur fringe and cyan cable glow were kept. No rembg pass was required.
- **Style / character references:** the official cyberpunk raccoon bandit front and side sprites (`anchor_front.png` and `anchor_side.png` from the current Neon City Bandit set), uploaded only as generation references. The earlier cute cartoon Trash Stack raccoon was not used.

## Animation pipeline test (idle)

One short side-view idle loop was generated to prove the sprite pipeline. This is a test only — not the full sprite set.

- **Model:** `wan2_7` (Wan 2.7), 2 seconds, 720p, 1:1, silent
- **Inputs:** the approved `shared/side-right.png` composited on a flat orange chroma (`#FF6A00`), used as both start and end frame
- **Job ID:** `46689765-682f-493a-8629-8ca392b3b21f`
- **Cost:** 3.0 credits
- **Not used:** the off-model orange-raccoon set in `/workspace/ncb-art2`, or the Higgsfield element `NCB-Bandit`
- **Local steps:** extract 60 frames at 30 fps, key out the orange background, fill leftover pockets (e.g. inside the cable loop), anchor every frame to 256×256 (bottom-center, shared crop so the feet stay planted), subsample a 10-frame loop

Files are under `anim-test/`.
